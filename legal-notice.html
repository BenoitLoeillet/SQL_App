SQL Editor — Database course

1 Site publisher

This application ("SQL App") is an educational tool made available to students as part of a relational databases / SQL course at emlyon business school.

Publisher: Benoit Loeillet — Contact: loeillet@em-lyon.com

Anonymous collection — no registration, no name, no e-mail required

2 Data collected

SQL App does not require an account, a username, or an e-mail address to be used. The only information recorded while using the tool is:

  • An anonymous session identifier — a code randomly generated by the browser (UUID) when the page is opened. It is neither a name, an e-mail, nor a student ID: it is only used to group the queries of a given work session. It is stored in the browser's sessionStorage and automatically disappears when the tab is closed.
  • The declared study program (BBA/GBBA, Master/MSc, or PGE), entered freely on first access, for statistical purposes only.
  • The SQL queries executed: the query text, the database used, the result (success/error), the number of rows returned and, where applicable, the error message.

No first name, last name, e-mail address, student number, or other personal identifier is requested or recorded by the application.

3 Purpose of the collection

This data is collected exclusively for educational and statistical purposes: tracking use of the tool throughout the course, identifying the most frequent SQL errors in order to improve teaching materials, and ensuring the service functions correctly.

It is neither used for commercial purposes, nor transferred, sold, or shared with third parties, and is never used to individually grade students.

4 Anonymous nature of the collection

The collection is designed to be anonymous by design ("anonymization by construction"):

  • No authentication is required to use the application.
  • The session identifier is a random code, not linked to an identity, regenerated for each new browsing session.
  • The study program is a general, non-identifying category (BBA/GBBA, Master/MSc, PGE).
  • No cross-referencing is performed between recorded queries and a student's identity.

As with any web service, the technical hosting provider (network infrastructure and database) may process standard connection metadata (such as an IP address) at a technical level, as part of the normal operation of the Internet — this information is neither used nor retained by SQL App itself.

5 Retention period

Session data is kept for the duration of the course / relevant academic year, for educational analysis purposes, and is then deleted or archived anonymously.

6 Your rights

Since no identifiable personal data is collected, requests for access, rectification, or deletion concerning a specific individual cannot be processed on a case-by-case basis (records cannot be linked to an identity).

For any question regarding this data collection or this tool, you can contact loeillet@em-lyon.com.
